When I vendor projects I usually only vendor the source the library code to
reduce overhead in the project source repo. Many use autoconf tools, and I
build with cmake instead. However, each of these projects come from a valid
open source licensed repository, which is documented here. Often I vendor
because different distros and platforms may not package or have updated
versions of libraries that I use.

incorporated in an upstream repository. These patches will also be maintained
in a public source repo and are licensed the same way as the patched package.
