# Kaigara - 介殻

A small collection of portable command line utilities. It's nothing really
special, mostly to exercise libcpr and friends, and to develop practices
around them with a standardized Cli utility package.

## Dependencies

Kaigara vendors its primary dependencies; libcpr, minicrypt, and libsiot.
Kaigara assumes a C17 (or later) C compiler with threading support is being
used.

## Distribution

Distributions of this package are provided as detached source tarballs made
from a tagged release from our internal source repository. These stand-alone
detached tarballs can be used to make packages for many GNU/Linux systems, and
for BSD ports. They may also be used to build and install the software directly
on a target platform.
